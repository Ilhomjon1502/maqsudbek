# Maqsudjon Turg'unaliyev

Sarbon universiteti, Axborot texnologiyalari yo'nalishi 1-kurs talabasining shaxsiy sayti.

- Kunduzgi (rangli) va tungi (oq-qora) rejim
- Animatsiyalar: yozilayotgan matn, scroll bilan paydo bo'lish, raqamlar sanog'i, 3D rasm
- Faqat HTML, CSS va JavaScript

Ko'rish uchun `index.html` faylini brauzerda oching.
